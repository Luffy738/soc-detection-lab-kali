# SOC Detection Lab – Kali Linux

This project demonstrates hands-on SOC Analyst skills by simulating real-world attacks and detecting them using log analysis,network traffic inspection, and MITRE ATT&CK mapping.

## Tools Used
- Kali Linux
- Hydra
- Nmap
- Wireshark
- tcpdump
- Linux authentication logs (auth.log)

## Attacks Simulated
- SSH Brute Force
- Network Reconnaissance

## Detection Techniques
- Linux log analysis
- PCAP analysis
- Time-based event correlation

## MITRE ATT&CK Mapping
- T1110 – Brute Force
- T1021.004 – SSH

## Outcome
- Detected malicious activity
- Correlated logs and network traffic
- Created SOC-style incident report
